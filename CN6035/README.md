# Εργασία CN6035 - Σύστημα Κρατήσεων Θεάτρου

## Τεχνολογίες
- **Backend:** Node.js, Express, JWT Authentication, MariaDB
- **Frontend:** React Native (Expo)

## Οδηγίες Εκτέλεσης
1. Εγκατάσταση εξαρτήσεων: `npm install`
2. Εκκίνηση Backend: `node server.js`
3. Εκκίνηση Frontend: `npx expo start`

## Τεχνική Σημείωση
Το Backend API είναι πλήρως λειτουργικό και έχει δοκιμαστεί επιτυχώς με το Postman (βλ. screenshots στο φάκελο /docs). 
Το Frontend είναι πλήρως υλοποιημένο. Λόγω ασυμβατότητας του τοπικού περιβάλλοντος Expo SDK με το runtime, ενδέχεται να απαιτείται clean install των dependencies για live preview.
